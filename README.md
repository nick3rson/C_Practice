## 🛠️ วิธี Compile

สำหรับการ Compile โค้ดภาษา C สามารถใช้ `gcc` ผ่าน Terminal ได้ดังนี้:

```bash
# Compile ไฟล์ .c ให้เป็นโปรแกรม
gcc -o output_name file_name.c

# รันโปรแกรมที่ Compile แล้ว
./output_name
```
